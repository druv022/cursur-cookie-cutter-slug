# Upstream skills catalog (reference)

This project vendors a **curated subset** of skills from upstream repositories.
To add more skills, edit `scripts/skills-manifest.json` and run `./scripts/update-skills.sh`.

## Vendored sources

- **addyosmani-agent-skills**: https://github.com/addyosmani/agent-skills.git (MIT)
- **ponytail**: https://github.com/DietrichGebert/ponytail.git (MIT)
- **superpowers**: https://github.com/obra/superpowers.git (MIT)
- **anthropics-skills**: https://github.com/anthropics/skills.git (Apache-2.0 (OSS skills only; docx/pdf/pptx/xlsx are source-available and excluded))
- **awesome-claude-skills**: https://github.com/ComposioHQ/awesome-claude-skills.git (Mixed; see upstream README per skill)
- **mattpocock-skills**: https://github.com/mattpocock/skills.git (MIT)
- **ui-ux-pro-max**: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git (MIT)
- **taste-skill**: https://github.com/leonxlnx/taste-skill.git (MIT)
- **karpathy-guidelines**: https://github.com/multica-ai/andrej-karpathy-skills.git (MIT)
- **i-have-adhd**: https://github.com/ayghri/i-have-adhd.git (MIT)
- **caveman**: https://github.com/JuliusBrussee/caveman.git (MIT)
